## Summary
Installs [jupyter-AI](https://jupyter-ai.readthedocs.io/en/stable/), a chat interface within jupyter that can use [goose AI](https://goose-docs.ai/) as a provider.

## Requires

* Debian-based system
* SRC Component: [SRC-Nginx Component](https://gitlab.com/rsc-surf-nl/plugins/plugin-nginx) must be executed prior to this component.
* A JupyterHub installation.
